# Next 1 · ניתוב ו-layouts

ניתוב לפי תיקיות ב-App Router: `page.tsx` ו-`layout.tsx`, `<Link>`, דפים דינמיים, layouts מקוננים ו-Route Groups, הקבצים המיוחדים `loading`, `error` ו-`not-found`, ו-Parallel ו-Intercepting Routes.

## מצגת

[`slides/next-lesson-01.html`](slides/next-lesson-01.html): מצגת שיעור 1: מ-React ל-Next. הורידו את הקובץ ופתחו אותו בדפדפן (GitHub מציג קובצי HTML כקוד).

## איך עובדים

בתיקייה [`starter/`](starter/) יש פרויקט Next.js נקי (create-next-app: TypeScript, Tailwind CSS, App Router). לכל תרגיל העתיקו אותו לתיקייה חדשה:

```bash
cp -r starter ex-1
cd ex-1
npm install
npm run dev
```
