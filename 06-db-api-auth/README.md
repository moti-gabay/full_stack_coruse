# Next 6 · מסד נתונים, API, proxy ואימות

צד השרת של Next: Route Handlers, חיבור Mongoose בתוך Next, `proxy.ts` להפניות ולהגנה, ואימות מלא עם בדיקת בעלות בכל Server Action.

## איך עובדים

בתיקייה [`starter/`](starter/) יש פרויקט Next.js נקי (create-next-app: TypeScript, Tailwind CSS, App Router). לכל תרגיל העתיקו אותו לתיקייה חדשה:

```bash
cp -r starter ex-1
cd ex-1
npm install
npm run dev
```
