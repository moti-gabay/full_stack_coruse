# תרגיל 6.4 · אימות מלא

**רמה:** מורכב · **זמן משוער:** 4 שעות

## המשימה

> Auth.js או Better Auth עם התחברות GitHub ועם סיסמה. דשבורד מוגן, ובדיקת בעלות בכל Server Action. להדגים התקפה: קריאה ל-action עם מזהה של משתמש אחר, ולהראות שהיא נחסמת

### רשימת דרישות

- [ ] Auth.js או Better Auth
- [ ] התחברות GitHub ועם סיסמה
- [ ] דשבורד מוגן
- [ ] בדיקת בעלות בכל Server Action
- [ ] להדגים התקפה: קריאה ל-action עם מזהה של משתמש אחר
- [ ] ולהראות שהיא נחסמת

## איך בודקים שזה עובד

- אפשר להתחבר גם עם GitHub וגם עם סיסמה.
- משתמש לא מחובר שנכנס לדשבורד מופנה להתחברות.
- קריאה ל-action עם מזהה של משאב של משתמש אחר נחסמת בשרת.
- ההדגמה של ההתקפה מתועדת: מה נשלח ומה חזר.

## קבצי התחלה

עובדים בתוך העתק של [`starter/`](../../starter/) של הנושא, פרויקט Next.js נקי. מריצים מתיקיית הנושא (`06-db-api-auth/`):

```bash
cp -r starter ex-6.4
cd ex-6.4
npm install
npm run dev
```
