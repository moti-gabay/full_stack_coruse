# פרויקט גמר · פלטפורמת מתכונים: API ב-Node וממשק ב-Next

**משך משוער:** 3–4 שבועות

התלמידים בונים שרת Express עם MongoDB, וממשק Next.js שצורך אותו. כך הם עובדים עם שני העולמות ומבינים מתי כל אחד מתאים.

## צד השרת (Express + MongoDB)

- [ ] משתמשים, הרשמה והתחברות עם JWT ב-cookie מסוג httpOnly
- [ ] מתכונים, תגיות וביקורות, עם ולידציה מלאה ובעלות על כל משאב
- [ ] סינון, חיפוש, מיון ועימוד
- [ ] `GET /stats` עם aggregation
- [ ] טיפול מרכזי בשגיאות, הגבלת קצב, ובדיקות עם supertest לנתיבים המרכזיים

## צד הממשק (Next.js)

- [ ] דפי מתכונים ציבוריים שמרונדרים בשרת עם SEO מלא
- [ ] חיפוש וסינון דרך ה-URL
- [ ] טפסים דרך Server Actions שקוראים ל-API, עם שגיאות ולידציה ליד כל שדה
- [ ] אזור אישי מוגן עם `proxy.ts`
- [ ] אסטרטגיית cache מתועדת לפחות לשני דפים

## לוח זמנים מומלץ

| שבוע | יעד | מה מציגים בסוף השבוע |
| --- | --- | --- |
| 1 | תכנון ו-API בסיסי | מודלים, CRUD מתכונים, אוסף בקשות עובד |
| 2 | אימות, קשרים ושאילתות | התחברות, ביקורות, חיפוש ועימוד |
| 3 | ממשק Next | דפים ציבוריים, טפסים ואזור אישי |
| 4 | ליטוש ופריסה | שני הצדדים חיים בכתובת אמיתית, והצגה בכיתה |

## מחוון ציונים

| קריטריון | משקל | מה מקבל ציון מלא |
| --- | --- | --- |
| פונקציונליות | 30% | כל דרישות החובה עובדות בפריסה החיה |
| ארכיטקטורה | 25% | הפרדה ברורה בין שרת ללקוח, מבנה תיקיות הגיוני, cache מנומק |
| אבטחה | 15% | סיסמאות מוצפנות, בדיקת הרשאה בכל פעולת כתיבה, אין סודות ב-repo |
| איכות קוד | 15% | קוד קריא, טיפוסים, טיפול בשגיאות, בדיקות לנתיבים המרכזיים |
| הצגה והסבר | 15% | התלמיד מסביר כל החלטה ועונה על "למה זה רץ בשרת?" |
