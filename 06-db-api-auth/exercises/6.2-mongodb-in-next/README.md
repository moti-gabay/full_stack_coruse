## המשימה

## איך בודקים שזה עובד

- יצירה, קריאה, עדכון ומחיקה דרך הממשק נשמרים במסד.
- שמירת קבצים ב-`npm run dev` לא פותחת חיבור חדש בכל פעם (הודעת החיבור מופיעה פעם אחת).
- נתונים שהמודל דוחה (למשל `title` של 2 תווים) לא נשמרים.

## קבצי התחלה

עובדים בתוך העתק של [`starter/`](../../starter/) של הנושא, פרויקט Next.js נקי. מריצים מתיקיית הנושא (`06-db-api-auth/`):

```bash
cp -r starter ex-6.2
cd ex-6.2
npm install
npm run dev
```
