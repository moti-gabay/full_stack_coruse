השאלה החדשה של הקורסTHE NEW QUESTION OF THIS COURSE

הקוד הזה רץ בשרת או בדפדפן?Does this code run on the server or in the browser?

ב-React התשובה תמיד הייתה דפדפן. ב-Next צריך לשאול אותה על כל קומפוננטהIn React the answer was always “the browser”. In Next you ask it about every component

אותה רשימת מתכונים, לפני ואחריThe same recipe list, before and after

React: שלושה states ו-useEffectReact: state and useEffect

function Recipes() {
  const [data, setData] = useState([]);
  const [loading, setLoading] = useState(true);
  useEffect(() => {
    fetch("/api/recipes")
      .then((r) => r.json())
      .then((d) => {
        setData(d);
        setLoading(false);
      });
  }, []);
  if (loading) return <Spinner />;
  return <List items={data} />;
}

ניתוב לפי תיקיות: תיקייה היא כתובתFolder-based routing: a folder is a URL

אין קובץ הגדרות routes. מבנה התיקיות בתוך app הוא הניתובThere’s no routes config file. The folder structure inside app is the routing

page.tsxהדף עצמו. בלעדיו לתיקייה אין כתובתThe page itself. Without it the folder has no URL
layout.tsxמעטפת משותפת שנשארת במקום בזמן ניווטA shared shell that stays in place while navigating
[slug]חלק דינמי בכתובת, מגיע ל-paramsA dynamic URL segment, available in params
<Link>במקום תגית a: ניווט בלי רענון ועם prefetchInstead of an a tag: navigation without a reload, with prefetching
app/
├── layout.tsx
├── page.tsx                → /
├── about/
│   └── page.tsx            → /about
└── recipes/
    ├── page.tsx            → /recipes
    └── [slug]/
        └── page.tsx        → /recipes/shakshuka
