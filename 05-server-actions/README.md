# Next 5 · Server Actions וטפסים

מוטציות בלי API: Server Actions וטפסים, `revalidatePath`, ולידציה עם Zod, `useActionState`, `useFormStatus` ו-`useOptimistic`, ובדיקת הרשאה בתוך ה-action.

## איך עובדים

בתיקייה [`starter/`](starter/) יש פרויקט Next.js נקי (create-next-app: TypeScript, Tailwind CSS, App Router). לכל תרגיל העתיקו אותו לתיקייה חדשה:

```bash
cp -r starter ex-1
cd ex-1
npm install
npm run dev
```
