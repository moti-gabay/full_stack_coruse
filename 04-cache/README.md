# Next 4 · רינדור ו-Cache

מתי ה-HTML נבנה: סטטי מול דינמי, Cache Components עם `"use cache"`, `cacheLife` ו-`cacheTag`, revalidation, Partial Prerendering, וקריאת הפלט של `next build`.

## איך עובדים

בתיקייה [`starter/`](starter/) יש פרויקט Next.js נקי (create-next-app: TypeScript, Tailwind CSS, App Router). לכל תרגיל העתיקו אותו לתיקייה חדשה:

```bash
cp -r starter ex-1
cd ex-1
npm install
npm run dev
```
