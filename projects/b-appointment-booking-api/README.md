# פרויקט Node ב׳ · מערכת תורים לעסק קטן

**משך משוער:** 5–7 ימים

## תיאור

קביעת תורים למספרה או לקליניקה. החלק הקשה הוא חוקי העסק, לא ה-CRUD.

## דרישות חובה

- [ ] שירותים עם משך ומחיר, ושעות פעילות לכל יום בשבוע
- [ ] `GET /slots?date=&serviceId=` מחשב חלונות פנויים בפועל
- [ ] אי אפשר לקבוע שני תורים חופפים (אינדקס unique או transaction)
- [ ] ביטול מותר רק עד 24 שעות לפני התור, אחרת 409
- [ ] תפקיד admin: רשימת תורים לפי יום, חסימת ימים (חופשות)
- [ ] בדיקות אוטומטיות לחישוב החלונות הפנויים ולמניעת חפיפה

## בונוס

- שליחת אישור במייל (אפשר mock), ותזכורת יום לפני.

## מה מגישים

- [ ] repo עם README
