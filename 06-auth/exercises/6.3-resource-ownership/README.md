# תרגיל 6.3 · בעלות על משאב

**בונה על:** תרגיל 6.2 (התחברות עם JWT). ממשיכים באותו פרויקט. את מודל המתכונים מעתיקים מתרגיל 4.3.

**רמה:** בינוני · **זמן משוער:** 60 דק'

## המשימה

> כל מתכון שומר `owner`. רק הבעלים יכול לערוך ולמחוק, אחרת 403. `GET /api/recipes/mine`

### רשימת דרישות

- [ ] כל מתכון שומר `owner`

## איך בודקים שזה עובד

- משתמש א׳ יוצר מתכון, ו-`owner` של המתכון הוא משתמש א׳.
- משתמש ב׳ מנסה לערוך או למחוק את המתכון ומקבל 403.
- משתמש א׳ עורך ומוחק בהצלחה.
- `GET /api/recipes/mine` מחזיר רק את המתכונים של המשתמש המחובר.

## איפה מתחילים

ממשיכים באותו פרויקט של תרגיל 6.2, מחוץ ל-repo הזה. אם אתם רוצים לשמור את הגרסה הקודמת, העתיקו את התיקייה לפני שמתחילים.

סודות והגדרות (פורט, כתובת המסד, מפתחות) נכנסים לקובץ `.env` מחוץ ל-Git, ולצידו `.env.example` בלי ערכים אמיתיים. מריצים עם `node --env-file=.env --watch server.js`.
