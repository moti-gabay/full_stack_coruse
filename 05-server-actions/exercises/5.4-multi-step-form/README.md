# תרגיל 5.4 · טופס רב-שלבי

**רמה:** מורכב · **זמן משוער:** 4 שעות

## המשימה

> אשף של 3 שלבים עם ולידציה בשרת בכל שלב, העלאת תמונה, ו-`redirect` בסיום. בדיקת הרשאה בתוך ה-action עצמו, ולהדגים מה קורה כשקוראים לו בלי הרשאה

## איך בודקים שזה עובד

- אי אפשר לעבור לשלב הבא עם נתונים לא תקינים, גם כשעוקפים את הדפדפן.
- התמונה מועלית ונשמרת.
- בסיום יש הפניה (`redirect`).
- קריאה ל-action בלי הרשאה נדחית בשרת, וההדגמה מתועדת.

## קבצי התחלה

עובדים בתוך העתק של [`starter/`](../../starter/) של הנושא, פרויקט Next.js נקי. מריצים מתיקיית הנושא (`05-server-actions/`):

```bash
cp -r starter ex-5.4
cd ex-5.4
npm install
npm run dev
```
