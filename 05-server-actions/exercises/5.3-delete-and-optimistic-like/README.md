# תרגיל 5.3 · מחיקה ולייק אופטימי

**רמה:** בינוני · **זמן משוער:** 60 דק'

## המשימה

> כפתור מחיקה עם אישור, ולייק שמתעדכן מיד עם `useOptimistic` וחוזר אחורה אם השרת נכשל

### רשימת דרישות

- [ ] כפתור מחיקה עם אישור

- [ ] וחוזר אחורה אם השרת נכשל

## איך בודקים שזה עובד

- מחיקה מבקשת אישור, וביטול לא מוחק.
- לייק מתעדכן מיד, גם כשה-action איטי.
- כשה-action נכשל (גרמו לכשל לבדיקה), מספר הלייקים חוזר לערך הקודם.

## קבצי התחלה

עובדים בתוך העתק של [`starter/`](../../starter/) של הנושא, פרויקט Next.js נקי. מריצים מתיקיית הנושא (`05-server-actions/`):

```bash
cp -r starter ex-5.3
cd ex-5.3
npm install
npm run dev
```
