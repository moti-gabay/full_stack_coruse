# תרגיל 4.4 · דוח build

**רמה:** מורכב · **זמן משוער:** 2–3 שעות

## המשימה

> להריץ `next build`, לקרוא אילו נתיבים סטטיים ואילו דינמיים, ולכתוב לכל נתיב למה. למצוא ולתקן נתיב אחד שהפך לדינמי בטעות

## איך בודקים שזה עובד

- בדוח מופיע כל נתיב מפלט ה-build, עם הסימון שלו והסיבה.
- לנתיב שתוקן יש פלט build לפני ואחרי, ואחרי התיקון הוא כבר לא דינמי.

## קבצי התחלה

עובדים בתוך העתק של [`starter/`](../../starter/) של הנושא, פרויקט Next.js נקי. מריצים מתיקיית הנושא (`04-cache/`):

```bash
cp -r starter ex-4.4
cd ex-4.4
npm install
npm run dev
```
