# תרגיל T.2 · מתארים נתונים

**רמה:** קל · **זמן משוער:** 20 דקות

## המשימה

כתבו קובץ `t2.ts` עם טיפוסים לאפליקציית מתכונים. **ייצאו** (`export`) את כל הטיפוסים והנתונים, כי התרגילים הבאים משתמשים בהם.

### רשימת דרישות

- [ ] `Difficulty`: אחד מ-`"easy"`, `"medium"`, `"hard"`
- [ ] `Unit`: אחד מ-`"g"`, `"ml"`, `"tsp"`, `"tbsp"`, `"cup"`, `"pcs"`
- [ ] `Ingredient`: `name`, `amount` (מספר), `unit`
- [ ] `Recipe`: `id`, `title`, `description` (אופציונלי), `difficulty`, `prepMinutes`, `ingredients` (מערך של `Ingredient`), `tags` (מערך מחרוזות), `createdAt` (תאריך)
- [ ] `User`: `id`, `name`, `email`, `role` (`"student"` או `"admin"`), `favorites` (מערך של מזהי מתכונים)
- [ ] מערך `recipes` עם 2 מתכונים לפחות, ומשתנה `user` אחד, עם הטיפוסים שהגדרתם

**ניסוי:** עשו בכוונה שלוש טעויות: רמת קושי `"hardd"`, יחידה `"kg"`, ומתכון בלי `title`. העתיקו את הודעות השגיאה להערה בקובץ, ואז תקנו.

## איך בודקים שזה עובד

`npx tsc --noEmit` עובר. כשכותבים ערך ל-`difficulty`, העורך מציע את שלוש האפשרויות.
