# פרויקט Node א׳ · API לניהול משימות

**משך משוער:** 3–4 ימים

## תיאור

מערכת בסגנון Trello מינימלי: משתמשים, פרויקטים ומשימות.

## דרישות חובה

- [ ] הרשמה, התחברות ו-JWT
- [ ] פרויקטים שייכים למשתמש, ורק הבעלים רואה ועורך אותם
- [ ] משימות עם `status` (todo, doing, done), `priority`, ו-`dueDate`
- [ ] סינון משימות לפי סטטוס ועדיפות, ומיון לפי תאריך יעד
- [ ] `GET /projects/:id/summary` שמחזיר כמה משימות בכל סטטוס
- [ ] טיפול מרכזי בשגיאות וקודי סטטוס נכונים

## בונוס

- שיתוף פרויקט עם משתמשים נוספים, ומשימות באיחור מסומנות אוטומטית.

## מה מגישים

- [ ] repo עם README
- [ ] קובץ `.env.example`
- [ ] אוסף בקשות (Postman או `requests.http`)
