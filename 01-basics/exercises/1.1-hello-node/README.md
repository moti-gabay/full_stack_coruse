## איך בודקים שזה עובד

- `node hello.js דנה` מדפיס את גרסת Node, את מערכת ההפעלה, את התאריך וברכה אישית עם השם דנה.
- `node hello.js` (בלי שם) מדפיס הוראות שימוש במקום ברכה.
