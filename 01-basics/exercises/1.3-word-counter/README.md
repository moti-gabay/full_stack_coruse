# תרגיל 1.3 · מונה מילים

**רמה:** בינוני · **זמן משוער:** 60 דק'

## המשימה

> קורא קובץ טקסט עם `fs/promises`, סופר שורות ומילים, ומוצא את 5 המילים הנפוצות. כותב את התוצאה ל-`report.json`. קובץ שלא קיים מדפיס הודעת שגיאה ברורה ולא קורס

## איך בודקים שזה עובד

- הרצה על קובץ טקסט לדוגמה יוצרת `report.json` עם מספר השורות, מספר המילים ו-5 המילים הנפוצות.
- על קובץ קצר שספרתם ידנית, המספרים ב-`report.json` תואמים.
- הרצה על קובץ שלא קיים מדפיסה הודעת שגיאה ברורה, בלי stack trace.
