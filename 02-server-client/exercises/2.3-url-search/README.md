# תרגיל 2.3 · חיפוש דרך ה-URL

**רמה:** בינוני · **זמן משוער:** 90 דק'

## המשימה

> הדף קורא `searchParams` ומסנן בשרת. שדה חיפוש בצד הלקוח מעדכן את ה-URL עם `useRouter` ו-debounce. רענון הדף או שיתוף הקישור שומרים את החיפוש

### רשימת דרישות

- [ ] הדף קורא `searchParams` ומסנן בשרת
- [ ] שדה חיפוש בצד הלקוח מעדכן את ה-URL עם `useRouter`
- [ ] עם debounce
- [ ] רענון הדף או שיתוף הקישור שומרים את החיפוש

## איך בודקים שזה עובד

- הקלדה בשדה מעדכנת את `?q=` בכתובת אחרי הפסקה קצרה, ולא בכל הקשה.
- התוצאות מסוננות, והסינון קורה בקומפוננטת השרת (לוג בדף מראה את החיפוש בטרמינל).
- רענון הדף שומר את החיפוש ואת התוצאות.
- פתיחת הקישור בלשונית חדשה מציגה את אותן תוצאות.

## קבצי התחלה

עובדים בתוך העתק של [`starter/`](../../starter/) של הנושא, פרויקט Next.js נקי. מריצים מתיקיית הנושא (`02-server-client/`):

```bash
cp -r starter ex-2.3
cd ex-2.3
npm install
npm run dev
```
